# Pinned Comment

## Choose the job

A pinned comment should do one of four things:

- add a detail that did not fit the post
- give a sharper punchline
- answer the obvious objection
- invite a useful discussion

Do not repeat the post's CTA.

## Output

Return one primary pinned comment and, when requested, a matching visual or meme brief.

Keep it short enough to feel like a real comment rather than a second post.
